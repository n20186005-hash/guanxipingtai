## 路線選擇速查表

| 你的情況 | 建議路線 | 時間 | 停留重點 |
| --- | --- | --- | --- |
| 第一次到安平、時間有限 | 半日精華路線 | 4–5 小時 | 兩個歷史景點＋海岸收尾 |
| 想完整走完安平 | 全日完整路線 | 8–9 小時 | 古蹟、老街、港灣與夕陽 |
| 帶幼兒或長輩同行 | 親子優先路線 | 3–4 小時 | 短距離移動、含休息與洗手間 |
| 想拍到好光線 | 光線優先路線 | 4–6 小時 | 日落前 90 分鐘進場到藍調時刻 |
| 行動不便、不耐久走 | 最短步行路線 | 1.5–2 小時 | 車輛直達、平台近端停留 |
| 沒有開車 | 無車旅客路線 | 5–6 小時 | 先確定回程，再排去程 |

同一趟旅行不需要全部走完。**選一條、留點空白**，體驗通常比趕行程更好。

## 經典安平半日遊

**安平古堡 → 安平老街午餐 → 安平樹屋 → 觀夕平台 → 安平晚餐**

這條路線適合第一次到安平。歷史景點與小吃集中在前半段，傍晚再向海岸移動。若老街排隊超過預期，可縮短購物時間，不要壓縮前往觀夕平台的交通緩衝。

建議至少預留 5–6 小時。出發較晚時，古堡與樹屋擇一即可。

## 安平親子一日遊

**台江遊客中心 → 親子午餐 → 億載金城或林默娘公園 → 觀夕平台**

上午先安排空間較舒展的景點，中午完整休息，下午選一個輕量活動，傍晚再玩沙與看夕陽。幼兒若需要午睡，可以直接刪除下午其中一站。

觀夕平台不建議下水，親子活動以乾沙、散步與看海為主。夏季要避免在最曝曬時段長時間待在戶外。

## 港灣與夕陽路線

**億載金城 → 安平港周邊 → 林默娘公園 → 觀夕平台 → 安平晚餐**

適合喜歡開闊地景、港灣與散步的旅客。整體移動範圍比老街路線分散，自駕或叫車較有彈性；騎自行車則要準備日落後照明。

如果風勢太強，可把公園停留縮短，提早到有遮蔽或室內的用餐地點。

## 台江自然路線

**四草周邊 → 台江國家公園遊客中心 → 安平用餐 → 觀夕平台**

四草船班與候船時間可能影響整天節奏，應排在上午，不要把傍晚船班與日落安排在一起。若遇到天候取消或延誤，直接改為台江遊客中心與安平市區，不必硬追原計畫。

## 無車旅客路線

**公車或叫車到安平 → 古堡／老街／樹屋擇二 → 提早前往觀夕平台 → 公車或叫車返程**

無車行程要先決定回程，再安排去程：

1. 查日落後仍可搭乘的公車與站牌方向。
2. 準備叫車作為備案，確認上車點與行動網路。
3. 不把四草、漁光島與觀夕平台等較分散海岸點全塞在同一天。
4. 天黑前回到照明與車輛可安全停靠的位置。

若住臺南中西區，可把安平集中排成一天。晚餐也可以回市區再吃，避免錯過回程交通。

## 攝影旅客半日路線

**安平樹屋 → 港灣地景 → 日落前 90 分鐘抵達觀夕平台 → 藍調時刻 → 晚餐**

白天先拍樹影與建築，下午觀察雲量與風勢，再決定是否攜帶腳架。日落後若要停留，先確認回程與照明，不為了畫面進入管制或濕滑區域。

## 通用路線 A：半日精華（約 4–5 小時）

**安平歷史景點擇一 → 老街午餐或點心 → 港灣散步 → 觀夕平台 → 晚餐**

| 時間 | 安排 | 重點 |
| --- | --- | --- |
| −4.5 小時 | 抵達安平，參觀古堡或樹屋擇一 | 有開放時間的景點先走 |
| −3 小時 | 老街用餐、補充飲水 | 尖峰排隊時間要算進去 |
| −1.5 小時 | 往海岸移動、找車位 | 假日再加 20–30 分鐘緩衝 |
| −1 小時 | 抵達觀夕平台，先熟悉環境 | 確認洗手間與回程動線 |
| 日落時刻 | 海岸看夕陽 | 站在動線外側，不擠在浪線邊 |
| 日落後 | 離開或就近晚餐 | 天黑前完成移動最從容 |

## 通用路線 B：全日完整（約 8–9 小時）

**上午台江或港區 → 午餐休息 → 午後安平老街與古蹟 → 黃昏觀夕平台 → 晚餐**

| 時段 | 安排 | 重點 |
| --- | --- | --- |
| 09:30–12:00 | 台江國家公園遊客中心或港灣地景 | 戶外為主，防曬與補水 |
| 12:00–14:00 | 午餐與休息（室內避開正午高溫） | 夏季務必安排這段緩衝 |
| 14:00–16:30 | 安平老街、古堡、樹屋擇二 | 留意各景點閉園時間 |
| 16:30–17:30 | 移動至海岸、找車位 | 這是最容易延誤的一段 |
| 日落前 1 小時 | 觀夕平台散步、等夕陽 | 提前選好不擋動線的位置 |
| 日落後 30 分鐘 | 晚霞與藍調，或直接用餐 | 先確認照明與同行者 |
| 晚餐 | 安平或回臺南市區 | 無車旅客優先考慮回程班次 |

全日路線的關鍵不是塞滿景點，而是**把最曬的時段留在室內**、把最舒服的光線留給海岸。

## 按人群定制的三條路線

### 1. 親子家庭路線（約 3–4 小時）

**安平老街午餐 → 洗手間與休息 → 觀夕平台玩乾沙 → 提早離開用餐**

- **移動半徑要小**：一天最多兩個主要停留點，孩子的情緒比行程表重要。
- **洗手間先安排**：抵達前與離開前各一次，不要假設現場一定有。
- **安全邊界先講好**：只在**乾沙**活動，不碰水邊；大人與孩子約好集合點。
- **裝備清單**：遮陽帽、防曬、換洗衣物、清水、野餐墊、垃圾袋。
- **避開時段**：夏季 11:00–14:00 不建議長時間戶外，改在室內休息。
- **提早離場**：日落前 15 分鐘就開始收拾，避免在黑暗中牽著孩子穿越人潮。

### 2. 攝影與自然愛好路線（約 4–6 小時）

**安平樹屋與港灣 → 觀察雲況 → 日落前 90 分鐘進場 → 黃金時刻 → 藍調時刻 → 收工**

- **先看雲量再決定**：薄雲能增加層次，厚雲則要有改拍地景與人像的備案。
- **腳本順序**：寬景（光線還亮）→ 剪影與人像（黃金時刻）→ 色溫（藍調）。
- **器材提醒**：腳架在強風時容易被吹倒，可加掛重物；鏡頭在海邊易沾鹽霧，收工後再清潔。
- **不要為了構圖越線**：堤防、消波塊與管制區不是取景點，風大時尤其危險。
- **延伸觀察**：喜歡自然主題的話，可以白天先走鄰近的濕地與潟湖，候鳥以**望遠鏡或長焦**觀察，保持距離。

### 3. 低體力與無障礙路線（約 1.5–2 小時）

**車輛直達平台近端 → 平台區停留 40–60 分鐘 → 原路返回 → 就近用餐**

- **先確認距離與鋪面**：出發前在地圖放大地形，確認停車位置到平台之間的距離、坡度與地面材質。
- **輪椅與輔具**：平台區通常比沙地適合，但**沙地不適合小輪推車**，不要硬推。
- **節奏建議**：抵達後先休息 10 分鐘再移動，避免在風中久站。
- **裝備清單**：摺疊椅或坐墊、飲水、防風外套、帽子（風大時以有綁帶者為佳）。
- **最好的時段**：日落前 40–50 分鐘抵達即可，不需要跟著人潮提早卡位。
- **重要提醒**：現場無障礙設施與動線會隨工程與活動變動，出發前請先確認最新狀況。

## 遇到天氣不好怎麼改

雷雨、颱風、長浪或強風時取消海岸行程。可改成安平室內展覽、老街短程用餐，或回臺南市區安排美術館、古蹟室內區與餐飲。

不要因為已經抵達安平就勉強前往海邊。夕陽每天都有，安全的旅行才有下一次。

## 排程時保留這些時間

- 找停車或等車：20–30 分鐘
- 景點間移動：依即時路況增加緩衝
- 日落前抵達：45–60 分鐘
- 日落後返程：至少 20 分鐘
- 週末排隊與用餐：再多留 30 分鐘

行程表留白，不是少玩一個景點，而是讓突發狀況不會拖垮整天。
